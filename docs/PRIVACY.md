# Nijatva Work Space — Privacy Policy

Version 1.0 · Effective 19 November 2026 · Contact: Vasudev.work@rediffmail.com

## Summary

Nijatva Work Space collects no personal data. It has no internet permission, no analytics, no advertising and
no crash-reporting code. Everything happens on the device.

## What the app accesses, and why

| Access | Why | Where the data goes |
|---|---|---|
| Installed apps list | Show apps; manage freezing, cloning, widgets | Stays on the device |
| All files access | Only while File Shuttle is on, to move files between profiles | Stays on the device |
| Display over other apps | Lets File Shuttle open file screens in the background | Stays on the device |
| Usage access | Powers Skip foreground apps | Stays on the device |
| Notifications | Shows freeze-service status | Stays on the device |
| Foreground service, alarms | Keeps the freeze service running after screen lock | Stays on the device |

## What Nijatva Work Space does not do

- Does not collect, transmit or sell personal data
- Has no account, sign-in or cloud sync
- Contains no analytics, advertising or tracking libraries
- Does not read messages, contacts, photos or browsing history

## Actions you start yourself

| Action | What happens |
|---|---|
| Send feedback | Opens your email app; nothing is sent until you press send |
| Support the developer | Shows a UPI QR; payment happens in your UPI app, Nijatva Work Space never sees it |
| Source code | Opens the project page in your browser |

## Work profile data

Work-profile apps and files are stored by Android in a separate space on the phone. Nijatva Work Space
manages that space but copies its contents nowhere. Removing the work profile or uninstalling
Nijatva Work Space deletes the data inside it.

## Data deletion

Nijatva Work Space stores only its own settings on the device. Uninstalling removes them; no server request is
needed because nothing was ever sent.

## Children

Nijatva Work Space is a device-management tool and is not directed at children under 13.

## Changes

If a future version changes how data is handled, this document is updated and the effective date
changed before that release.
